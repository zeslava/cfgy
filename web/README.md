# CFGY Web

Веб-дашборд CFGY: Svelte 5 + SvelteKit, `adapter-static` (SPA). Сборка в `web/build/` встраивается в бинарь `cfgy`.

```bash
npm install
npm run dev     # localhost:5173 (или task web из корня)
npm run build   # → web/build/ (или task build-web)
```

Общая документация — в корневом [README.md](../README.md).
