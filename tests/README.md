# Smoke-тесты для CFGY API

Интеграционные smoke-тесты для проверки всех сценариев работы CFGY API.

## Структура

- `smoke_tests.rs` - основной файл с тестами
- `Cargo.toml` - зависимости для тестов

## Запуск тестов

### Предварительные требования

1. Запущен PostgreSQL (можно через `docker compose up -d`)
2. Применены миграции (`psql -f server/migrations/001_initial_schema.sql`)
3. Запущен сервер на `http://localhost:8080`

### Запуск

```bash
# Из корня проекта
cargo test --bin smoke_tests

# Или конкретный тест
cargo test --bin smoke_tests test_auth_register_and_login
```

## Покрытие тестов

### ✅ Аутентификация
- Регистрация пользователя
- Вход пользователя

### ✅ Управление проектами
- Создание проекта
- Получение проекта по ID
- Список проектов
- Обновление проекта (имя, описание, оба)
- Частичное обновление проекта
- Удаление проекта

### ✅ Управление окружениями
- Создание окружения
- Список окружений

### ✅ Управление секретами
- Установка секретов
- Получение секретов
- Обновление секретов
- Удаление секрета
- Секреты со специальными символами
- Изоляция секретов между окружениями

## Особенности

- **Уникальные данные**: Каждый тест генерирует уникальные email и имена проектов для избежания конфликтов
- **Изоляция**: Каждый тест создает свои данные и очищает их после выполнения
- **HTTP клиент**: Используется `reqwest` для асинхронных HTTP запросов
- **Логирование**: Тесты выводят прогресс выполнения для удобной отладки

## Настройка

По умолчанию тесты подключаются к `http://localhost:8080`. Чтобы изменить URL сервера, можно:

1. Отредактировать константу `BASE_URL` в `smoke_tests.rs`
2. Или использовать переменную окружения (можно добавить поддержку)

## Добавление новых тестов

1. Создайте новую функцию с атрибутом `#[tokio::test]`
2. Используйте `TestClient` для выполнения запросов
3. Используйте helper функции `test_email()` и `test_project_name()` для генерации уникальных данных
4. Не забудьте очистить созданные данные в конце теста

## Пример теста

```rust
#[tokio::test]
async fn test_my_feature() -> Result<()> {
    let mut client = TestClient::new(BASE_URL);
    let email = test_email();
    let password = "testpass123";

    // Регистрация и вход
    client.register(&email, password).await?;
    let login_response = client.login(&email, password).await?;
    client.set_token(login_response.session_token.unwrap());

    // Ваш тест здесь
    // ...

    Ok(())
}
```
