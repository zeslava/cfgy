# Завершение задачи

## При изменениях в Rust
```bash
cargo fmt
cargo clippy
cargo check
cargo test
```
Если менялись handlers/router/миграции — дополнительно:
```bash
task e2e     # поднимает сервер сам; требует доступной БД (task up)
```

## При изменениях в web/
```bash
cd web && npm run check     # svelte-check
npm run build               # проверка, что сборка адаптером static проходит
```

## При изменении схемы БД
- есть обе миграции (`.up.sql` + `.down.sql`), up идемпотентна (`IF NOT EXISTS`);
- `task migrate` применяется на чистой БД без ошибок;
- сущность в `ports/entities.rs` синхронизирована со схемой.

## Не делать без явной просьбы
- добавлять тесты, логирование, обработку ошибок сверх нужного;
- коммитить и пушить.
